# الخطة | متابعة الجودة والإنتاج

## النشر على GitHub Pages

GitHub Pages يستضيف الواجهة الثابتة فقط؛ لا يشغّل خادم Flask أو قاعدة بيانات SQLite. لنشر واجهة React:

1. من إعدادات المستودع، افتح **Settings → Pages** واختر **GitHub Actions** كمصدر النشر.
2. ارفع التغييرات إلى فرع `main`. سير العمل في `.github/workflows/deploy.yml` سيبني الموقع وينشره تلقائيًا.

المسارات النسبية في إعداد Vite تدعم عنوان GitHub Pages الذي يحتوي على اسم المستودع. الواجهة الحالية تحفظ بياناتها محليًا في المتصفح، لذلك لا تُشارك البيانات بين المستخدمين. للتشغيل المشترك باستخدام Flask وSQLite، انشر الخادم على استضافة تدعم Python مثل PythonAnywhere.

## التشغيل محليًا

ثبّت [Bun](https://bun.sh/)، ثم نفّذ:

```sh
bun install
bun run dev
```
